# Getting started

TurboLoader's getting-started material lives in two places now:

- **[Quickstart](quickstart.md)** — install, the training fast path, labels via `meta['indices']`, resume, TBL-RAW, other modalities.
- **[Installation](installation.md)** — wheels matrix (cp310–cp314, Linux x86_64/aarch64, macOS arm64), CUDA build flags, cu13 wheels.

Everything else is on the **[project wiki](https://github.com/ALJainProjects/TurboLoader/wiki)** — start with [Which loader do I use?](https://github.com/ALJainProjects/TurboLoader/wiki/Which-Loader-Do-I-Use).
